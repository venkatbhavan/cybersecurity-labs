# Web Fundamentals

This section documents my hands-on learning and practical exercises in web application security.

## Topics Covered

- Web application technologies
- Web application offense and defense
- Web reconnaissance
- Web application vulnerability assessment
- CMS enumeration
- Web security tools

## Tools

- Burp Suite
- OWASP ZAP
- Nmap
- Nikto
- Gobuster
- WPScan

## Lab Environment

The practical exercises are performed in isolated, intentionally vulnerable laboratory environments.

## Objectives

- Understand how web applications communicate
- Analyze HTTP requests and responses
- Perform reconnaissance and enumeration
- Identify common web application vulnerabilities
- Understand offensive and defensive security concepts
- Document findings professionally
